**Description

My projects on Supervised and Unsupervised Machine learning algorithms namely: Linear Regression and Principal Component Analysis. Some brief overview of the concepts and background required to learn and understand these concepts. 

Implementing complementary machine learning systes: a facial analysis program using Principal Component Analysis PCA from scratch using Python3 standard libraries, Numpy, Scipy and matplotlib

The input file is from the Kaggle dataset (https://www.kaggle.com/datasets/jessicali9530/celeba-dataset)

The original full-resolution dataset contains 202, 599 sample images of 10, 177 celebrities, each of size 218 × 178. The input file used in this script is a compressed file of from 218×178 to
60 × 50. 

##some abbreviations 
n and d are number of images and number of features. (n=100) for each sample image (d = 60 × 50 = 3000).
xi to refer to the ith sample image which is a d-dimensional feature vector
